# Civil Engineering 331 (CE 331)

## Hydrology

**Brigham Young University**

Course content for CE 331, rendered with MkDocs on Read the Docs. Each lesson in `docs/unit*/` has a pre-class page (`*_read.md`), an in-class page (`*_class.md`) and a homework page (`*_hw.md`, ending with its grading rubric).

Answer keys, worked solutions and grading notes are not in this repository.

To preview locally:

```
pip install mkdocs pymdown-extensions python-markdown-math
mkdocs serve
```
