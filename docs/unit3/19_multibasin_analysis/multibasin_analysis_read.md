# Pre-Class - Multi-basin Analysis

Real watersheds are rarely uniform, so hydrologists divide them into subbasins, compute a runoff hydrograph for each one, route those hydrographs downstream, and add them at confluences to get the hydrograph at the outlet. This lesson covers why watersheds are subdivided, the convolution, routing and summation workflow, the role of linearity, and why routing matters when combining subbasin hydrographs.
