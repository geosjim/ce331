# In-Class - SCS Curve Number

We will work these examples together in class. Each one is the same type of problem as a homework problem, with different numbers.

Excel starter file: [SCS Curve Number Example Template.xlsx](SCS%20Curve%20Number%20Example%20Template.xlsx)

Equations:

$$CN_w = \frac{\sum A_i\,CN_i}{\sum A_i} \qquad S = \frac{1000}{CN} - 10 \qquad I_a = 0.2S$$

$$Q = \frac{(P - 0.2S)^2}{P + 0.8S}, \quad \text{valid when } P > 0.2S$$

# Example A - Composite CN with Mixed Land Use and Soil

A 40-acre suburban-edge catchment receives a P = 4.0 in design storm. The catchment is split between two land uses on different soils:

- 70% pasture, good condition, Soil Group B, CN = 61
- 30% residential ½-ac lots, Soil Group C, CN = 80

Use the SCS CN method to find the weighted CN, S, $I_a$, the runoff depth Q, and the runoff coefficient Q/P. (The area is not needed for Q.)

Find: weighted CN, S, $I_a$, runoff depth Q (in), and runoff coefficient Q/P.

# Example B - Sensitivity to Storm Size and to a Land-Use Change

A 100-ac watershed is currently 100% wooded (good condition) on Soil Group C, CN = 70.

a. Compute S and Q for two storms over the existing land use: Case A, P = 1.5 in; Case B, P = 4.5 in.<br>
b. Land-use change: 30% of the watershed is converted to commercial (85% impervious, Soil Group C, CN = 94). Recompute the composite CN and Q for the larger storm (P = 4.5 in).<br>
c. Comment on how storm size and imperviousness shift the runoff.

Find: S and Q for both storms (CN = 70), the composite CN after the change, and Q for P = 4.5 in after the change.

# Example C - Comparing CN with Horton and Green-Ampt

You are reviewing a stormwater design report and need to recommend which infiltration / loss model to use for three different projects:

1. A rural design-storm peak-flow estimate for a small, ungaged Wasatch watershed.
2. A research study quantifying ponding and runoff during a 90-minute high-intensity thunderstorm on a clay-loam test plot.
3. A continuous urban-stormwater model that must track soil moisture between storms over a wet spring.

For each project, recommend Horton, Green–Ampt, or SCS CN and justify the choice in one sentence.
