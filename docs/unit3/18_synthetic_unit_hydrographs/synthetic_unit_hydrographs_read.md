# Pre-Class - Synthetic Unit Hydrographs

Most watersheds have no streamflow record from which to derive a unit hydrograph, so engineers build synthetic unit hydrographs from watershed characteristics such as area, length, slope and curve number. This lesson covers the Snyder and SCS (NRCS) synthetic unit hydrographs, lag time and time of concentration, peaking factors, the Clark unit hydrograph, and applying unit hydrographs to watersheds with several subareas to build a design storm hydrograph.
