# Textbook and References

## Textbook

We will be using *Hydrology and Floodplain Analysis* by Bedient, Huber, and Vieux, Sixth Edition. You should either purchase the hardcopy or the e-text for this class. More information on ordering can be found at [booklist.byu.edu](https://booklist.byu.edu/).

Each lesson's Pre-Class page lists the textbook sections to read before class.
