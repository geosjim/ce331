## Semester at a Glance

The course tracks water through the hydrologic cycle:

| | Theme | Topics |
|---|---|---|
| 1 | Overview | The hydrologic cycle, water balance |
| 2 | Atmosphere | Weather, precipitation, snow |
| 3 | Landing on the land | Evaporation, evapotranspiration, infiltration, runoff |
| 4 | Tracking on the land | Watersheds, data, statistics |
| 5 | Producing a hydrograph | Curve number, unit hydrographs, multi-basin analysis |
| 6 | Moving water downstream | Routing, urban hydrology, design storms |
| 7 | Going underground | Darcy's law, wells |

## How Class Works

**Before class (about 1 hour, due 8:00 am).** Read the assigned text sections, answer the pre-class questions in the Canvas quiz, and bring one question you want us to cover.

**First half of class (about 20 minutes).** Review the concepts together, discuss the pre-class responses and fill gaps in understanding.

**Second half of class (about 30 minutes).** Work the in-class example problems, set up the homework together and practice the skills for the next exam.
