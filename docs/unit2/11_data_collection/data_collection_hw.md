# Homework - Data Collection

Gather some historical streamflow and precipitation data for gauges near Spanish Fork.

1. Download the daily average discharge data for the Spanish Fork Castilla station from 1935 to present.

2. For the Spanish Fork River at Utah Lake, download the GEOGLOWS retrospective daily data (unregulated flow in m³/s) from the [hydroviewer](https://hydroviewer.geoglows.org/).

3. Load your two data sets into Excel, Sheets, or some other tool and create a plot. You may want to choose a given year so it isn't so large, as the purpose is just to demonstrate that you can discover data and open it in the simplest way for analysis.

4. Download monthly total precipitation for the Spanish Fork Power House station for the years 2016 to 2025 and create a plot of interest on a second sheet.

Turn in your Excel worksheet.

See [Water Data for the Nation](https://waterdata.usgs.gov/) and the [In-Class page](data_collection_class.md) for help finding and downloading the data.
