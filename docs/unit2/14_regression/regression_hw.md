# Homework 13 - Regression

**Deer Creek Reservoir Watershed, Utah (2001-2010).** Annual data for snow water equivalent (SWE), temperature, and streamflow discharge from CUAHSI stations near Hideout, Jordanelle, and Woodland, UT. Ten years of annual data - SWE (inches), temperature (°C), and discharge (cfs) - are already included in the homework template, along with helper columns.

Using the data included in the homework template:

1. **SWE vs. Discharge Regression** - Develop a linear regression model with annual SWE as the independent variable and discharge as the dependent variable. Compute the slope (b), intercept (a), and $R^2$.

2. **Temperature vs. Discharge Regression** - Repeat using annual average temperature as the independent variable.

3. **Prediction** - If next year's annual SWE is 1,100 inches, what discharge do you predict? If next year's annual average temperature is 4.6 °C, what discharge do you predict?

4. **Compare & Interpret** - Which predictor better explains discharge? Why does this make physical sense for this watershed?

Hint: expect one predictor to have a much higher $R^2$ than the other.
