# Pre-Class - Regression

This lesson covers regression in hydrology: fitting a simple linear model by ordinary least squares and judging it with $R^2$, regional regression equations for estimating flows at ungaged sites, the basin and climate characteristics used as predictors, watershed and stream classification (Strahler and Shreve stream orders, Pfafstetter codes, HydroBASINS), and the U.S. hydrologic data sources used to build these models.

## Reading

Bedient, Huber & Vieux, *Hydrology and Floodplain Analysis*, 6th ed., Sections 3.7 (Regional Analysis) and 3.8 (Related Topics).

## Pre-Class Questions

### Question 1 - Why Regional Analysis

Explain why regional regression equations are useful when we need to estimate the 100-year peak discharge at a stream site that has only 8 years of gage record (or no record at all).

### Question 2 - Simple Linear Regression Mechanics

Write the equations for the slope b and intercept a of an ordinary least-squares fit y = a + b x, and state what R^2 measures.

### Question 3 - Predictors for Ungaged Basins

List four basin or climate characteristics that are commonly used as independent variables in regional regression equations for streamflow, and briefly explain why each is physically meaningful.

### Question 4 - Stream Ordering Schemes

Compare Strahler and Shreve stream ordering. For a confluence where a Strahler order-2 stream meets another order-2 stream, what is the resulting stream order under each scheme?

### Question 5 - U.S. Hydrologic Data Sources

Name the standard U.S. data product (and the agency that maintains it) for each of the following: stream centerlines, surface elevation, soil properties, land cover, and streamflow gage records.
