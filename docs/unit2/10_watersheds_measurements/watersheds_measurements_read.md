# Pre-Class - Watersheds and Measurements

This lesson covers the watershed as the basic unit of hydrologic analysis and how the main hydrologic variables are measured: precipitation with rain gauges, streamflow with the velocity-area method and stage-discharge rating curves, and the public data sources that hydrologic engineers in the U.S. use every day.

## Reading

Bedient, Huber & Vieux, *Hydrology and Floodplain Analysis*, 6th ed., Sections 1.8 (Hydrologic Measurement) and 2.1 (Watershed Concepts).

## Pre-Class Questions

### Question 1 - Defining a Watershed's Physical Properties

Identify 2-3 physical properties that strongly affect how that watershed responds to a storm.

### Question 2 - Measuring Precipitation

How does a tipping-bucket rain gauge measure rainfall, and name one physical effect that can cause an installed gauge to under-report the rain that falls.

### Question 3 - Measuring Streamflow: the Velocity-Area Method

Streamflow at a gauging station is normally measured by the velocity-area method. Describe in one or two sentences how a discharge measurement is built up from individual cross-section measurements.

### Question 4 - Stage-Discharge (Rating) Curve

In one or two sentences, explain why streamflow gauges typically record only stage (water-surface elevation) and how that recorded stage is converted to discharge.

### Question 5 - Real-World Data Sources

Name two public data sources that a hydrologic engineer in the U.S. would routinely use, briefly describe what each one provides, and identify one project task you might use it for.
